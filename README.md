# Ruang Warga Sa’ar Kleco — Ready to Publik

Versi Laravel yang dipersiapkan untuk deployment Vercel tanpa menyertakan rahasia lokal.

Fitur utama:

- Beranda dan pengumuman terhubung agenda
- Kas Warga dengan perhitungan otomatis
- Agenda warga
- Galeri Google Drive dan lightbox
- Data pengurus
- Login admin dengan password hash
- Metadata thumbnail saat tautan dibagikan
- Penyimpanan persisten melalui PostgreSQL

Baca [DEPLOY-VERCEL.md](DEPLOY-VERCEL.md) sebelum deployment.
